# Glemt å avslutte økta — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fullføres en økt som har vart over 3 timer, spør et bunnark hvor lenge du trente, og den tiden lagres som varighet.

**Architecture:**
- Grensen, forslaget, tolkningen av feltene, datoteksten og den endelige varigheten er rene funksjoner i `longSession.ts`.
- `completeWorkoutSession` tar en valgfri varighet og bruker `finalDurationMinutes`.
- `LongSessionSheet.vue` er arket. `WorkoutSession.vue` åpner det fra `handleCompleteWorkout` i stedet for `confirm()` når økta er lang.

**Tech Stack:** Vue 3 og TypeScript. Selvsjekken bundles med esbuild og kjøres i Node.

**Spec:** `docs/superpowers/specs/2026-11-19-glemt-okt-design.md`

## Global Constraints

- **Git og stil:** ikke commit, stage, branch eller push. Kommentarer på engelsk og UI-tekst på bokmål. Bruk `my-vue-style` (script → template → style), og ikke omformater hele filer.
- **Grensen:** `> 180` minutter. Akkurat 3 timer gir ikke ark.
- **Forslaget:** snitt av de siste 8 fullførte øktene fra malen med `0 < duration <= 180`, avrundet. Ellers 60, og da uten hjelpetekst.
- **Selvsjekk:** `npx esbuild <scratchpad>/check-long-session.ts --bundle --platform=node --format=esm --log-level=warning --outfile=<scratchpad>/check-long-session.mjs && node <scratchpad>/check-long-session.mjs`. Til slutt `npm run type-check` og `npm run build`.

## Review Focus

1. **En tidligere glemt økt blant de 8 siste** trekker ikke forslaget opp (Task 1, steg 1).
2. **En økt uten mal** (`templateId` null eller slettet mal) gir 60 og ingen hjelpetekst (Task 1, steg 1).
3. **Minutter over 59, bokstaver eller tomt felt** gir et fornuftig tall: sifre beholdes, minutter maks 59, tomt er 0 (Task 1, steg 1).
4. **Kondisjon med lengre aktiv tid enn det som skrives inn** får den aktive tiden (Task 1, steg 1).
5. **Arket lukkes og åpnes igjen** med forslaget fylt inn på nytt, ikke det som ble skrevet sist. Sjekkes manuelt i Task 3.
